# Release signing key (public half)

- `release-signing.pub` — ed25519 ssh public key for VIRP release manifest
  signatures (created 2026-08-20).
- `allowed_signers` — `ssh-keygen -Y verify` input binding the identity
  `virp-release@thirdlevelit.com` to that key, restricted to the
  `virp-release` namespace.

The private key is operator-held (default path
`~/.virp/release-signing.key`, see `RELEASE_KEY` in the Makefile) and is
never committed, never generated by CI. CI signs only when the
`RELEASE_SIGNING_KEY` GitHub secret is explicitly configured; releases are
otherwise still signed via the workflow's keyless Sigstore attestation.

To rotate: generate a new ed25519 key, replace both files here in a
reviewed commit, and revoke the old one by noting the rotation date in
this file. Verification and usage: `docs/RELEASE-PROVENANCE.md`.
